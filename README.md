# 全生命周期数字底座 · 系统使用说明

[在线演示](https://zhenminglan.github.io/digital-base-demo/) · [GitHub](https://github.com/zhenmingLan/digital-base-demo)

本项目为静态前端交互演示，不连接真实 Autodesk 服务、模型解析或传感器。运行：在本目录执行 `python3 -m http.server 8765`，浏览器访问 `http://127.0.0.1:8765`。

## 第一次使用 · 先看这里

先认识系统，再用一份成果和一台设备走一遍。无需先了解所有菜单。

左上角按应用切换：道路接入与建模、Forma Data Management、Forma Build、Autodesk Tandem。Data Management 管理共享文件与协作，Build 管理现场工作，Tandem 按设施组织数字孪生。应用切换不会复制文件，也不代表完成交付。Tandem 顶部“主页、设施、管理”为账户导航，打开设施后左侧才显示模型、资产和连接等工具。

### 这个系统解决什么问题

一个工程项目从设计到施工，再到运营，会不断产生文件、现场记录和设备数据。本系统把这些信息放在同一项目背景下，让你既能找到资料，也能知道它属于哪个工程对象、用于哪项工作，以及与前后阶段的什么记录有关。

例如：设计人员关心“桥梁设计成果是哪一版”；施工人员关心“这项安装工作用了哪些图纸、检查是否完成”；运营人员关心“这台风机在哪里、手册在哪里、振动读数从哪里来”。设计、施工、运营面向不同任务，道路接入与建模另行负责数据接入与三维生成，因此目录和页面组织也不同。

### 页面上的四个区域

- 左上角阶段菜单：选择道路接入与建模、Forma Data Management、Forma Build或Autodesk Tandem；同一示例项目中切换工作场景。
- 左侧导航：选择当前阶段要做的事，例如查文件、处理现场问题或看设备读数。
- 中间工作区：目录、列表、模型或看板；搜索、筛选和点击选择通常在这里进行。
- 右侧详情：显示当前选中的文件、记录或资产。先核对名称和编号，再查看属性或执行操作，避免在错误对象上操作。

### 首次体验，建议这样走

1. 先阅读“系统逻辑与阶段衔接”，理解文件、工作包与资产的区别。
2. 进入“Forma Data Management操作”，按例子打开桥梁设计模型，查看它的版本与空间位置。
3. 进入“Forma Build操作”，找到通风系统安装工作包，沿文件关联打开风机记录。
4. 进入“Autodesk Tandem操作”，选择 FAN-01，查看数据来源链、设备属性和振动趋势。

读完后，你应能回答三个问题：我现在在哪个阶段？我选中的是文件、业务记录还是资产？这条数据的来源是什么，下一步应该去哪里核对？

### 阅读时不用担心离开当前任务

右上角问号随时可打开本说明。点击左侧章节只切换说明正文；“返回页面”回到刚才的工作区。正文里的蓝色页面链接会进入相应模块，当前未保存的弹窗内容请先处理完。

当前开放的是演示版：可以练习查找、关联、填写和流程操作，部分入口只演示配置步骤。下面会在涉及这些入口时说明结果；真实文件上传、审批发送和传感器接入不在本版本中执行。

## 系统逻辑与阶段衔接

同一个项目，三种工作视角；靠来源、版本和对象标识衔接，而不是靠页面切换。

### 先分清四类信息

- 文件：图纸、报告、手册、检查附件等资料。查看时要核对名称、编号、版本和状态。
- 业务记录：问题、审阅、报审、技术澄清和检查事项。它们记录谁负责、何时处理、当前走到哪一步，并可引用文件。
- 工程对象 / 资产：桥梁、隧道或一台具体设备。它说明资料和工作服务于什么对象。
- 监测读数：某个时间采集的数值，需要说明测点、宿主、参数、单位和时间；它不是模型文件里的静态属性。

### 为什么三个阶段的树不一样

Forma Data Management按成果目录和 EBS 查“哪个工程对象的资料”；EBS 可理解为工程对象的分解。Forma Build按 WBS 查“哪项工作包的资料”；WBS 是工作的分解。Autodesk Tandem按设施、空间、系统和资产查“哪台设备在哪里、属于哪个系统”。一台设备可以同时有模型元素、施工记录和运营读数，但这些信息各有自己的编号。

### 以风机 FAN-01 为例

在Forma Build，它是“通风系统安装”工作包有关的设备；在Autodesk Tandem，它是隧道通风系统中的一台资产。模型元素标识用来找到模型中的对象，FAN-01 用来识别业务资产，连接和数据流标识用来找到它的监测读数。文档通过明确的关联挂到资产上，不会因为文件名里出现“风机”就自动绑定。

### 设计 → 施工 → 运营，应该怎么交接

1. 设计阶段先明确成果用途、版本和接收要求，审阅与发行用于控制哪些成果可供下游使用。
2. 施工阶段引用适用图纸，记录报审、现场问题、检查、安装和调试结果，并把文件归到工作包。
3. 交付前核对竣工模型、设备编码、调试记录、手册和接收要求，确认资料是否可追溯。
4. 运营阶段核对模型元素与资产，补齐参数和文档，再配置监测连接；日常从模型、资产清单和看板使用这些信息。

### 在页面上核验一次跨关联来源

1. 在Autodesk Tandem“资产清单”选择 FAN-01，确认右侧资产编号。
2. 点击顶栏“关联来源”，阅读设计、施工、运营三栏的来源和提示。
3. 点击“定位施工设备 FAN-01”，进入Forma Build对应设备记录；核对设备编号和安装 / 移交状态。
4. 从该设备记录的“定位后续运营示例”返回运营资产，确认仍是 FAN-01。

预期结果：两端定位同一台设备，同时保留各阶段自己的状态。FAN-01、PUMP-01、DB-01 已有显式示例映射；其他对象提示未关联时，应补来源，不要把附近工点或同名文件当作来源。

### 当前来源不完整时怎么看

桥梁和隧道的设计成果只能作为基础参考，不等于已批准施工图。管理站设计成果来源、施工图设计源文件、审查发行记录和已验收竣工交付包仍有缺口。“待建立关联”表示资料链尚未闭合，不是点击失败。

施工页展示 2026-09-11，运营页展示预置的 2026-10-11 后续场景。切换阶段不会自动复制文件、同步施工状态或完成移交；两个日期也不表示同一时刻的实时状态。

## Forma Data Management操作 · 找资料与协作

Forma Data Management维护共享成果资料库；道路接入与建模独立配置输入数据并生成三维，再归档回资料库。

### 页面用途与数据来源

Forma Data Management按路、桥、隧组织设计成果，通过模型编码与构件编码建立协作关系。

### 按步骤使用

1. 在成果资料库上传并分类管理来源文件。
2. 切换道路接入与建模，从资料库选择导入或额外上传，再配置和生成三维。
3. 归档后回到Forma Data Management，在成果资料库或空间场景选择文件、目录、构件并开展协作。

### 结果与下一步

当前标签页内保存演示配置和协作记录，刷新可继续；关闭标签页后不保证保留。没有真实工程文件上传、EI 解析、消息发送或审批。设计模型不等于已批准施工图，切换阶段不代表移交。

## Forma Build操作 · 工作包与现场事项

项目文件以 WBS 为归档主线，现场记录通过引用连接图纸、工作包与设备。

### 任务一：按安装工作找到资料

入口：左上角“Forma Build” → “项目文件”。这里按 WBS 工作包归档，而不是按设备清单组织。

1. 从“合同段 T1”进入“隧道机电工程 → 通风系统安装”（T1.02.01）。
2. 查看当前目录的图纸、报审、调试和移交文件；使用资料类型或搜索缩小范围。
3. 选择“风机单机调试记录”（DOC-013），在右侧核对主归属 WBS 和关联项 FAN-01。
4. 点击关联业务 FAN-01，查看施工设备记录。用浏览器返回可恢复文件详情。

预期结果：你既知道文件放在哪个工作包，也知道它关联哪台设备。WBS 是工作范围，ACT 是计划活动编号，设备编码是资产身份，它们不能互相替代。

### 任务二：在工作包里归档一份资料

1. 先进入目标工作包；如果仍在父目录，点击“归档文件”后必须选择目标工作包。
2. 输入文件名称并选择资料类型，点击“添加索引示例”。
3. 查看新增文件详情，核对它的主归属；返回列表确认记录已出现。

预期结果：当前标签页新增一份归档索引，不上传真实附件。每份文件一个主归属，关联多个业务时通过引用连接。

### 任务三：沿问题找到技术澄清与后续处理

1. 进入“现场问题”，选择 ISS-001“桥台预埋件位置与施工图不一致”。
2. 先读问题描述，核对工点、责任人、截止日期和关联施工图。
3. 使用“关联 / 创建 RFI”查看或建立技术澄清关系，进入关联 RFI 后核对提问和答复。
4. 根据记录允许的操作推进处理，或查看潜在变更。回到问题记录确认当前状态，不要把 RFI 已答复直接理解为现场已整改。

处理逻辑：问题负责跟踪现场事项，RFI 负责技术澄清，成本与变更负责影响评估。它们相互引用，但不会因为其中一项完成就自动全部关闭。

### 任务四：检查和设备交付分别在哪里看

- “质量与安全表单”：填检查项；不符合项可创建问题继续整改。完成检查表不等于整改全部完成。
- “设备与移交”：查看安装、调试及资料准备情况；确认缺口后再推进相应阶段。
- “进度计划”：从活动查看工作包和关联事项；不要用文件数量判断进度完成率。
- “项目报表”：汇总当前示例业务的状态与逾期事项，便于找到仍需处理的记录。

## Autodesk Tandem操作 · 建立关联与使用数据

按设施、空间、系统和资产组织运行信息，不沿用施工文件夹作为运营导航。

### 先判断：你是准备数据，还是日常使用？

第一次了解数据如何建立，请从“接入配置”开始。已经有资产数据、只想查看设备时，直接进入“资产清单”“数字孪生”或“仪表板”。不需要每次查看读数前重新导入模型。

### 任务一：用 FAN-01 走完数据配置流程

入口：“Autodesk Tandem → 接入配置”。在顶部设施选择器确认“K14+000 隧道”，在右侧来源链选择 FAN-01。当前使用预置模型与设备，可先练习，不必准备文件。

1. 第 1 步“导入源模型”：点“导入模型”，选择本地文件或点“使用预置示例文件”，再点“下一步”。阅读来源、版本和坐标设置，继续到确认页并保存草稿。此时只是记录导入方案，场景不会变成所选文件的真实模型。
2. 第 2 步“关联资产数据”：点“配置资产关联”，选 FAN-01，核对源模型和模型元素标识；下一步核对 AssetCode、制造商、序列号和文档，选择制造商来源，确认空间 / 系统关系后保存草稿。
3. 第 3 步“接入传感器”：点“接入传感器”，选宿主 FAN-01，填写外部测点标识并选接入路径。下一步数值字段可用 value，时间戳字段可用 timestamp，单位沿用 mm/s。两个字段不能同名，单位需与目标参数一致。
4. 继续到样例载荷页，核对测点、宿主、时间、数值和单位，再保存配置草稿。样例校验通过只说明字段配置可用，不表示现场已连通。
5. 第 4 步“核验并使用”：查看配置草稿和剩余来源缺口，再选择“查看数字孪生”或“继续交付核验”。

预期结果：你理解了“模型 → 元素 → 资产 → 连接 → 数据流”的关系，并记录了一份练习方案。右侧仍是预置资产的来源链；左侧草稿不会覆盖它，刷新会清除草稿。

### 任务二：查看一台设备在哪里、属于哪个系统

1. 进入“资产清单”，确认设施为隧道，搜索 FAN-01 并点击资产行。
2. 右侧核对资产名称、空间位置、关联系统、模型元素和运营参数。资产编码识别设备，模型元素标识定位几何对象。
3. 点击“模型定位”进入数字孪生。需要缩小范围时使用系统、空间或状态筛选；选择后核对右侧仍为目标资产。
4. 切换“文档”页签查看手册；点击“阶段来源与交付核验”核对资料来源，或查看施工设备关联。

预期结果：设备在空间、系统和资料中的身份能对应起来。切换设施后应重新核对选中资产；筛选无结果时先清除筛选，不要认定资产已被删除。

### 任务三：解释读数，而不只看颜色

1. 进入“数据流”，选择 FAN-01，阅读监测参数“振动速度”和单位 mm/s。
2. 核对数据流、连接、宿主资产和最后接收时间，再查看曲线及预警 / 超限线。
3. 切换 6 小时 / 24 小时范围观察趋势；需要配置时进入“阈值设置”，核对预警上限与超限上限。
4. 点击“在模型中定位”查看宿主；需要追查来源时回到“接入配置”的传感器步骤。

正常、预警、超限取决于读数与阈值；离线表示未获得有效在线读数，未接入表示尚无连接。空值不是 0，也不表示正常。当前曲线为 2026-10-11 预置序列，不是实时监测。

### 任务四：补齐资产资料，检查交付准备

1. 进入“数据交付”，阅读受影响资产及缺失项。初始样例中 PUMP-02 有资料缺口；如果已被修改，以当前列表为准。
2. 点击对应资产的“补齐数据”，按字段填写并保存；缺少手册时可填写资料名称，或从资产文档页使用“关联文档”。
3. 点击“检查交付”，查看缺失项与完整率是否变化。
4. 字段齐全后仍要核对真实文档内容、来源版本和接收要求，不能把 100% 当作验收完成。

## 保存与演示范围

区分页面交互、浏览器会话数据与真实业务操作。

### 哪些内容会保留

- 施工业务记录、变更与表单填写，运营资产编辑和阈值，以及 WBS 新增归档索引，使用当前标签页的浏览器会话缓存；正常离开页面或刷新时会保存相关数据。

- 保存视图、部分筛选与布局属于当前页面状态，不承诺刷新后保留。Forma Data Management创建、上传、审阅和分发主要展示流程，不保存真实业务。
- 新标签页或不同访问地址不保证共享会话。关闭标签页、清除浏览器数据或浏览器限制存储，可能丢失演示编辑。

### 如何恢复初始演示

### 导出与附件

- 施工业务列表 / 项目摘要及运营资产清单的 CSV 导出在浏览器本地生成；右上角本说明的“下载 README”也会下载本地文件。
- Forma Data Management导出与运营活动记录导出为提示性入口，不生成对应业务文件。
- 文件、图纸和模型采用索引、SVG 或预置预览；下载、上传、发布、连接、审批与通知不会操作真实工程数据或发送消息。

## 常见问题

按页面上实际出现的状态排查。

### 文件夹收起后怎么展开？

Forma Data Management点击有箭头的目录行可重新展开；Forma Build点击节点左侧箭头。无箭头的末级目录没有子目录，但点击名称仍可查看文件。

### 目录里为什么看不到文件？

先检查搜索和资料类型。Forma Build默认只展示当前层级，进入子文件夹或勾选“包含下级”即可查看下级文件。树上的数字是包含下级的总数。

### 点击文件后没有右侧详情？

Forma Data Management可用文件列表右上角的面板按钮打开详情，再选择文件。Forma Build点击文件行即打开详情，右上角 × 可关闭。

### 为什么运营设备不能全部跳到施工记录？

只有 FAN-01、PUMP-01、DB-01 建立了显式设备映射。其他对象保持未关联，需补充来源后才能形成可靠追溯。

### 完整率达到 100% 就移交完成了吗？

不是。页面完整率只核对必填参数是否填写，还需业务准确性、文档、版本、设备状态及接收验收核验。

### 修改消失或页面仍是旧版怎么办？

先确认仍在原标签页和相同访问地址。更新前端文件后刷新页面；若样式仍旧，可强制刷新。会话缓存不是永久存储，需要重新开始演示时用“关联来源”中的重置入口。

## 常用术语与查找方法

遇到缩写或不熟悉的对象，先用这里判断它是什么、该去哪里看。

### 资料与工作

- CDE / 公共数据环境：围绕项目文件、版本和协作记录共享资料的工作环境。本系统各阶段共享项目背景和明确的资料引用。
- EBS / 工程分解：从工程对象角度组织内容；Forma Data Management空间场景用它浏览成果。
- WBS / 工作分解：从工作范围角度组织施工资料；末级工作包是文件主归属。
- ACT / 进度活动：计划中的具体作业，可关联 WBS；编号不是文件夹名称。
- RFI / 技术澄清：用于提出和答复技术疑问，与现场整改记录分开。
- 报审：材料、设备或方案提交审查；审阅：对成果开展检查；分发：把指定版本交给接收方。

### 模型与运行

- 设施：隧道、桥梁、管理站等运营管理范围；先选设施再查资产。
- 空间：设备所在的房间或区域；系统：设备所属的功能网络。一台风机可以在左洞，同时属于通风系统。
- 模型元素：模型中的一个对象，以源模型及元素标识定位。
- 资产：需要管理参数、资料或运行信息的业务对象，例如 FAN-01。
- 宿主：承载某条监测数据的对象。传感器测点和宿主设备可能不是同一件东西。
- 连接：接入设备或数据来源的数字表示；数据流：某个监测参数按时间排列的读数。
- 参数映射：指定来源字段填入哪个资产参数，例如 Manufacturer 对应制造商。
- 完整率：按必填信息是否填写计算；不证明内容真实、设备合格或已完成验收。

### 按问题选择查找方式

- 知道资料名称：到相应阶段的文件列表搜索，同时检查当前目录。
- 知道工作范围：Forma Build先选 WBS，再查资料或进度关联。
- 知道设备编号：Autodesk Tandem资产清单搜索；看不到时确认设施范围。
- 想知道信息来源：先选对象，再打开“关联来源”；Autodesk Tandem还可查看“接入配置”的来源链。

需要找具体模块时，道路接入与建模、Forma Data Management、Forma Build和Autodesk Tandem章节中提供全部页面入口。需要重新开始练习时，先阅读“保存与演示范围”，再使用重置操作。

| 页面入口 | 可以做什么 |

### 按步骤使用

1. 确认设施并选择目标数据流，例如 FAN-01 振动速度，先读单位和最后接收时间。

### 容易误解的地方与当前版本范围

## 道路接入与建模

独立的道路接入与建模应用。以路线为范围，导入 EI 文件、配置路桥隧参数，再生成和归档预览。

页面：[道路接入与建模](road-modeling.html)

左上角阶段菜单按道路接入与建模、Forma Data Management、Forma Build、Autodesk Tandem排列。道路接入与建模属于道路接入与建模；成果资料库仍在Forma Data Management，两个阶段共享文件索引。

### 页面用途与数据来源

按参考设计流程配置路线数据、道路横断面、桥梁布跨和隧道断面，核验后生成当前路线的路桥隧组合预览。

### 按步骤使用

1. 从左上角选择道路接入与建模，进入道路接入与建模。上半区查看模型，下半区编辑配置表；拖动两区之间的分隔条可调整高度。默认 K 主线提供参数示例，路线数据需要选择导入；也可主动载入示例数据练习。
2. 先切换Forma Data Management → 成果资料库，在具体子目录点击上传文件；也可从根目录上传时选择保存位置。上传 ICD、SQX、DMX 等数据后回道路接入与建模，分别在平曲线、竖曲线、地面线栏选择相应文件。资料库文件详情中的切换道路接入与建模并选择导入可携带该文件打开导入窗口。
3. 路线 / EI 数据页签按路线列出平曲线 ICD、竖曲线 SQX、地面线 DMX、断链 TXT（本演示约定）、横地线 HDX、构造物 GZX 六个独立入口。点击某一栏打开导入窗口，优先从成果资料库选择对应类型的文件，固定其编码、路径与版本；也可切换额外上传，拖入或选择非空文件。确认导入后显示文件来源。必需的前三类缺失时不能生成；其他类型按需提供。当前版本只检查扩展名，不实际解析 EI 内容。
4. 用添加路线建立路线编码、名称、路线包、类型和起终点桩号；编辑可以修改这些属性。通过当前路线选择器指定本次配置范围。新增路线需补齐数据并添加示例桥梁、隧道，才可演示组合建模。
5. 坐标系配置记录 CGCS2000/WGS84、投影、分带、中央子午线、假东假北、投影面高程及高程异常；坐标仅随模型归档，不进行真实转换。
6. 路基路面设计表设置道路等级、设计速度、设计线与标高线偏距。打开横断面库，选择四、六、八车道模板，编辑路缘带、车道、硬路肩、土路肩和中央分隔带等尺寸；断面图与总宽实时更新。
7. 桥梁总体设计表按所属路线配置名称、中心桩号、跨径组合、幅类、交角、上部结构、桥墩、桥台与墩高。布跨窗口支持 4×30 或 30+40+30 等组合，并显示桥墩位置与总长。每条示例路线配置一座桥梁。
8. 隧道总体设计表按路线配置起终点桩号、断面类型、内轮廓半径、衬砌厚度、横向间距、扫掠方式与内插间距。段落长度由起终点计算。每条示例路线配置一座隧道。
9. 点击核验并生成预览。系统检查必需数据、桥隧范围与重叠、车道数与隧道断面等；按提示返回相应页签修正。结构类型等属性会归档，几何仅由车道宽度、跨径、墩高和隧道尺寸等部分参数驱动，不执行设计验算。
10. 用道路近景、桥梁近景、隧道洞口查看细节；鼠标拖动旋转、Shift 加拖动平移、滚轮缩放。模型为带材质和光影的几何示意，线形与纵向比例经过简化。
11. 归档当前路线将更新成果库里路、桥、隧三个示例模型的版本并保存本次完整配置，不会新增第二套模型目录；已有问题与分发仍保留旧版本快照。刷新或返回建模页可读取已归档配置。
12. 数据栏的移除数据会删除本路线的引用或额外上传索引，不删除成果资料库原文件。资料库源文件被删除时会显示来源失效，重新生成前需要恢复或更换。已归档模型和历史协作快照不变；修改后的接入配置保存在本标签页会话。

### 结果与下一步

当前标签页内保存演示配置和协作记录，刷新可继续；关闭标签页后不保证保留。没有真实工程文件上传、EI 解析、消息发送或审批。设计模型不等于已批准施工图，切换阶段不代表移交。

### 工作台布局与配置进度

左侧按路线数据、路基路面、桥梁、隧道列出步骤，可直接点击切换配置页；侧栏显示必需文件数量、可用 EI 文件和归档版本。顶部流程条展示导入、配置、生成、归档顺序，中央三维与下方配置表之间可拖动调整。

### 勾选删除建模数据

每个已接入文件上方都有复选框；路线行复选框选择该路线全部已接入文件，表头复选框全选当前表格。点击删除所选文件，确认后移除对应引用或额外上传索引，成果资料库原文件不删除。未接入的空栏不能选择；必需文件删除后需重新导入才能生成。
